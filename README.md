# Noticall

Progetto Android nativo per Noticall.

## Come ottenere l'APK direttamente
1. Carica **il contenuto di questa cartella** nella root del repository GitHub.
2. Apri **Actions → Build Noticall APK → Run workflow**.
3. Aspetta il segno verde.
4. Vai nella pagina principale del repository → **Releases**.
5. Apri l'ultima release `Noticall Test ...`.
6. In **Assets** scarica direttamente `Noticall-test.apk`.

GitHub mostra anche un artifact ZIP nella pagina dell'Action: è normale. La Release invece espone il file APK direttamente.
