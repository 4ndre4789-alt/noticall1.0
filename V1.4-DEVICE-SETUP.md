# Noticall v1.4 — Configurazione dispositivo

Nuovo onboarding guidato per rendere l'automazione affidabile anche con schermo spento.

- Permessi Telefono / Registro chiamate / SMS
- Notifiche foreground service (Android 13+)
- Richiesta esclusione ottimizzazione batteria
- Samsung: deeplink ufficiale a **App mai in sospensione**
- Avvio automatico dopo riavvio/aggiornamento
- Controllo dinamico dello stato del dispositivo
- Attivazione automatica di Noticall a configurazione completata

L'utente deve confermare le modifiche nelle schermate Android/Samsung: l'app non aggira le protezioni del sistema.
