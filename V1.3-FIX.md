# Noticall v1.3 – SMS Capability Fix

Correzione specifica per dispositivi che riportano erroneamente `FEATURE_TELEPHONY_MESSAGING=false` pur riuscendo a inviare SMS.

## Modifica principale
- Rimosso il blocco preventivo `PackageManager.FEATURE_TELEPHONY_MESSAGING`.
- Noticall ora tenta sempre l'invio reale tramite `SmsManager` quando `SEND_SMS` è concesso.
- Restano attivi selezione SIM, foreground service, wake lock e diagnostica dello stato SMS.

## Test consigliato
1. Compila con GitHub Actions.
2. Installa la nuova APK sopra la precedente.
3. Attiva Noticall e imposta ritardo 5 secondi.
4. Blocca lo schermo.
5. Effettua una chiamata persa da un secondo telefono.
6. Verifica in Attività: CHIAMATA -> PROGRAMMATA -> INVIO -> SENT oppure un errore reale del modem/operatore.
